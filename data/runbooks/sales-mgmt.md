# 売上管理システム 運用手順書

## システム概要
各店舗のレジから売上データを受信・集計するシステム。APサーバー(Java / Spring)+ Cloud SQL 構成。
システムID: sales-mgmt

## 既知事象: 売上送信タイムアウト(DB接続プール枯渇)
- 症状: レジからの売上送信がタイムアウトする。エラー率が上昇する。
- ログの特徴: `HikariPool-1 - Connection is not available, request timed out` の繰り返し、`pool usage: active=50/50`(接続プール使用率100%)。
- 原因: DB接続プールの枯渇(コネクションリーク)。
- 対応: **APサーバーの再起動**(common-restart.md の標準手順に従う)。再起動で接続プールが解放され回復する。
- 恒久対応: コネクションリークの改修(開発チームのバックログ管理)。

## 既知事象: TLS証明書の期限切れ
- 症状: レジから接続エラー(証明書エラー)が発生する。
- 対応: 証明書の更新が必要。インフラ運用チームへエスカレーションする。
